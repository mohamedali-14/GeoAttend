# 📍 GeoAttend - Smart Attendance Management System

**GPS Location Tracking | Selfie Verification | AI-Powered Quizzes | Real-time Analytics**

GeoAttend is a comprehensive attendance management system that combines GPS tracking, facial verification, random code checks, and AI-generated quizzes to ensure accurate, cheat-proof attendance for educational institutions.

---

## 🚀 Features

### Core Features

| Feature | Description |
|---------|-------------|
| **📍 GPS Location Tracking** | Students must be within a specified radius to mark attendance |
| **📸 Selfie Verification** | Optional photo verification per session (professor chooses) |
| **🔐 Random Check Codes** | Time-sensitive verification codes for additional security |
| **🤖 AI Quiz Generation** | Generate 10 questions from lecture PDFs using DeepSeek LLM |
| **📊 Real-time Dashboard** | Live attendance tracking and updates for professors |
| **📑 Export Reports** | Generate Excel, PDF, CSV, and JSON reports |
| **📈 Analytics Dashboard** | Attendance statistics, trends, and engagement metrics |
| **⚠️ Performance Monitoring** | At-risk student detection and professor alerts |

### User Roles

| Role | Capabilities |
|------|--------------|
| **👨‍🏫 Professor** | Create sessions, set verification rules, review selfies, generate reports, view analytics |
| **👨‍🎓 Student** | Mark attendance, take selfies, take AI quizzes, view history, receive notifications |
| **👨‍💼 Admin** | Manage users, monitor system, view metrics |
